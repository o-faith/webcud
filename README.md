This is the FACET-II Web Display which shows real time data from the FACET-II accelerator. It includes linac settings, final focus, spectrometer, schedule of experiments, 3 bunch charge 24 hour history graphs, and more. The LCLS Web Display was used to make this web page.

These files are needed for this display: facet.html, facetcud.css, facetcud-Socket.js, webPV-Socket.js, facet-index.html, metricsgraphics.css, and metricsgraphics.min.js.

facet.html: input PVs, units for each PV, APIs for scheduled program and bunch charge graphs, settings for graphs

facetcud.css: create sections for layout, colors, font-size, logo placements

facetcud-socket.js: emittances and bmag color range, conversion for Waist Target and BC2 Peak Current PVs

facet-index.html: spacing for each PV, settings for bunch charge graphs
